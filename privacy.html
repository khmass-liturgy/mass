가톨릭 신앙생활 포털

시행일: 2026년 8월 21일 · 최종 수정일: 2026년 8월 21일

가톨릭 신앙생활 포털은 회원가입이나 광고·행동 분석 기능을 운영하지 않습니다. 사용자가 선택한 경우에만 주변 성당을 찾기 위해 대략적인 위치를 사용하며, 위치정보는 기기 안에서만 거리 계산에 이용하고 개발자 서버로 전송하거나 저장하지 않습니다.

1. 적용 범위

이 방침은 Android 앱 가톨릭 신앙생활 포털과 앱에서 제공하는 웹 포털에 적용됩니다. 운영자는 GitHub 사용자 khmass-liturgy입니다.

2. 처리하는 정보와 이용 목적

선택적 대략적 위치정보

  • 처리 시점: 사용자가 내 주변 성당 찾기 기능을 직접 실행하고 위치 권한을 허용한 경우
  • 이용 목적: 앱에 포함된 성당 위치 자료와 비교하여 가까운 성당을 거리순으로 표시
  • 처리 방식: 기기 안에서만 계산하며 개발자 서버로 전송·저장하지 않음
  • 선택 가능성: 권한을 거부해도 주변 성당 찾기 외의 기능은 계속 이용 가능

서비스 접속 과정에서 처리될 수 있는 기술정보

웹페이지 제공과 보안을 위해 호스팅 제공자인 GitHub Pages 및 글꼴 제공자인 Google Fonts가 IP 주소, 브라우저·기기 정보, 접속 시각, 요청 주소 등의 일반적인 접속정보를 처리할 수 있습니다. 운영자는 이를 광고, 사용자 추적 또는 행동 분석에 이용하지 않으며 별도의 분석 도구를 설치하지 않았습니다.

기기에 저장되는 정보

일부 화면의 글자 확대 설정은 브라우저 로컬 저장소에 보관될 수 있으며, 오프라인 표시와 빠른 로딩을 위해 정적 페이지와 자료가 앱의 웹 캐시에 저장될 수 있습니다. 이 정보에는 이름, 이메일, 연락처 등 사용자를 직접 식별하는 정보가 포함되지 않습니다.

3. 외부 서비스와 링크

포털에는 가톨릭 기관 사이트, YouTube, Google 캘린더, Kakao 지도 등 외부 서비스로 이동하는 링크가 있습니다. 링크를 선택하면 해당 서비스가 자체 개인정보처리방침에 따라 정보를 처리할 수 있습니다. Kakao 지도에서 성당 길찾기를 선택할 때에는 선택한 성당의 명칭 또는 주소가 검색어로 전달되며, 앱이 계산에 사용한 현재 위치 좌표는 전달하지 않습니다.

  • Google 개인정보처리방침
  • Kakao 개인정보처리방침

4. 보유기간과 삭제

  • 위치정보: 개발자 서버에 전송하거나 보유하지 않으며, 기기 내 거리 계산이 끝난 뒤 별도로 저장하지 않습니다.
  • 글자 확대 설정과 웹 캐시: 사용자가 앱 데이터·캐시를 삭제하거나 앱을 제거할 때까지 기기에 남을 수 있습니다.
  • 외부 제공자의 접속기록: 각 제공자의 개인정보처리방침과 보유정책에 따릅니다.

이 서비스는 자체 회원계정을 만들지 않으므로 별도의 회원 탈퇴나 계정 삭제 절차가 없습니다.

5. 이용자의 선택과 권리

위치 권한은 Android 설정의 앱 권한에서 언제든지 거부하거나 철회할 수 있습니다. 기기에 저장된 설정과 캐시는 Android 설정에서 앱 데이터 또는 캐시를 삭제하거나 앱을 제거하여 삭제할 수 있습니다. 개인정보 처리에 관한 문의나 정정·삭제 요청은 아래 연락처로 보내주세요.

6. 안전성 확보 조치

앱 내부 웹페이지는 HTTPS로만 불러오며 평문 HTTP 혼합 콘텐츠를 차단합니다. Android 앱에서는 제3자 쿠키를 허용하지 않으며, 카메라·마이크·연락처·사진·파일 권한을 요청하지 않습니다.

7. 아동의 개인정보

이 서비스는 종교·신앙생활 정보를 제공하는 일반 이용자용 서비스이며 아동을 대상으로 개인정보를 수집하는 기능을 운영하지 않습니다.
